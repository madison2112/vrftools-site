How to Use

Upload a .dsbx file on the Central Controller Config Tools page, then click DSBX to DAT to open it here. Groups are auto-populated from the DSB data. You can double-click any group tag name to edit it inline, and click the controller name above the grid to rename it. Edit IP addresses as needed. Drag cards to reorder groups before downloading.
